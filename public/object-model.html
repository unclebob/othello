Othello as objects

Projection of the current Clojure design onto an OO model. Namespaces become classes; maps become values or a single session entity. The dependency rule does not change.

Layers

Same rings as the Clojure modules. Color is mean function CRAP from clj -M:crap. Labels show μ / max / σ (population SD). Adapters run hot because Quil drawing is not exercised by Speclj.

≤ 1.5 1.6 – 2.5 > 2.5 not measured (CLJS)

Domain

Values, not entities. play and undo return a new Game. Rules is policy over a board — legal moves do not live on Board. A disc is a color in a square; there is no Piece class.

AI

Player is the port that ai/move already is. Desktop and browser inject different search budgets. Tests inject a fake (greedy, first-legal, or nil).

UI application

Session is the one object with identity — the UI state machine. ViewModel is a read-only projection; it does not tick or play. Buttons and keys share one command table, not a Command hierarchy. Phases stay an enum. A State pattern would be ceremony.

Adapters

Quil/p5 stays in the painter and the two apps. The job port is the only difference between desktop future and browser setTimeout.

A turn

Click d3. The session starts a flip animation without committing the domain. When the animation finishes, Game.play commits. The host then launches a Player job for White.
